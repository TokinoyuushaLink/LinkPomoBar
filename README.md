# LinkPomoBar
一个简单的，功耗极低的番茄钟应用\
包含基本的番茄钟功能：预设时长，自定义时长，周期数量调整，秒数与分钟切换。

A simple and superless power comsumption pomodoro app made with claude and gemini . \
Includes basic tomato clock features: duration preset, customized duration, period number adjustment, seconds and minutes switching.

*language currently avaliable on chinese and english , switch according to system language automatically .
